MDTEX overview:
LaTeX and Markdown are two of the most popular markup languages on the market today; LaTeX is a feature-rich, high-level ecosystem which appeals to academics while Markdown is lightweight and fast to appeal to developers. We propose MDTeX as a way to bridge the two ecosystems together and provide a common markup language which both academics and developers can take advantage of.

Some of the features we want to include will be:
Users should be able to create a new project environment using MDTeX as a project management tool
Users should be able to add and remove packages as dependencies from the LaTeX ecosystem using explicit or declarative package management
Users should be able to write a mix of Markdown and LaTeX, in accordance with the MDTeX file format specifications
Users should be able to style a document using a HTML/CSS or LaTeX template file
Users should be able to compile MDTeX source files into a PDF or HTML document
